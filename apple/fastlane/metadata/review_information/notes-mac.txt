FIX FOR THE REPORTED ISSUE (Guideline 2.1(a), white screen at launch)
Fixed since build 9 (this submission: version 1.0.2, which also adds a short opening animation that can be skipped with a click). The app's web view could not start inside the App Sandbox, which caused the white screen. The missing sandbox entitlement (outgoing connections, needed by WebKit's own helper processes) has been added, and the app now opens directly to the planner. The app still makes no network requests; all content is bundled in the app. We tested the build from TestFlight on a MacBook, after removing the previous version.

1. PURPOSE AND AUDIENCE
Technical Officials Scheduler plans the Technical Officials (referees) of triathlon races. Its users are race organisers, technical delegates and chief officials of triathlon clubs, national federations and event organisers anywhere in the world. From the races (format, date, start time) and the list of officials it gives every official a position, adds short jobs without time clashes, books the required meetings (athletes' briefing, Jury meetings, rehearsals), counts radios and warns about conflicts. The result can be viewed as a list, personal schedules, a Gantt chart and a timeline, and exported to Excel, calendar files or pictures.

2. HOW TO USE IT (no login, no sample files needed)
- On first launch an example event opens (two Elite races, 18 placeholder officials "TO 01"–"TO 18").
- Plan → Assignments: the generated plan. Choose another official in any row; the plan updates and the row is locked.
- Setup → Races / Officials / Meetings & briefings: change start times, add races or officials.
- Views → Gantt / Personal schedules / Timeline. Athletes → Athletes' guide.
- More → Export & share (or File → Export & Share…, ⌘E): saves Excel, calendar (.ics), pictures or the plan file with the standard save panel.
- Events → New event (⌘N); events are saved automatically on the Mac.
